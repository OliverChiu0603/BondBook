# 用户登录和头像显示问题排查指南

## 问题现象
设置页面显示"微信用户"和"ID: ***"，而不是真实的头像和昵称。

## 原因分析

### 1. 用户未登录
最常见的情况是用户还没有点击"点击登录"按钮进行授权。

### 2. 用户取消了授权
用户点击登录后，在授权弹窗中选择了"拒绝"。

### 3. wx.getUserProfile API问题
- 小程序基础库版本过低（需要 >= 2.10.4）
- 在开发工具中可能无法正常获取真实头像
- 需要在真机上测试

### 4. 云数据库未创建
users集合未创建或权限设置不正确。

## 解决步骤

### 步骤1：确认基础库版本
在微信开发者工具中：
1. 点击右上角"详情"
2. 查看"本地设置" - "调试基础库"
3. 确保版本 >= 2.10.4

### 步骤2：创建users集合
1. 打开云开发控制台
2. 进入"数据库"
3. 点击"新建集合"
4. 输入集合名：`users`
5. 权限设置：
   - 所有用户可读
   - 仅创建者可写

### 步骤3：部署login云函数
确保login云函数已正确部署：
1. 右键 `cloudfunctions/login/`
2. 选择"上传并部署：云端安装依赖"
3. 等待部署完成

### 步骤4：用户登录流程
1. 打开小程序设置页面
2. 点击"点击登录"按钮
3. 在弹出的授权窗口中点击"允许"
4. 等待登录成功提示
5. 刷新页面，应该能看到头像和昵称

### 步骤5：真机测试
开发工具中可能无法获取真实头像，建议：
1. 使用"预览"功能生成二维码
2. 用手机扫码打开
3. 在真机上测试登录功能

## 常见问题

### Q1：点击登录后没有反应
**A：** 检查以下几点：
- 网络连接是否正常
- 云开发环境是否已初始化
- 查看控制台是否有错误日志

### Q2：显示"登录失败，请重试"
**A：** 可能原因：
- login云函数未部署或部署失败
- users集合未创建
- 云函数权限问题

### Q3：真机上仍然显示"微信用户"
**A：** 
- 清除小程序缓存后重试
- 删除小程序重新扫码进入
- 确认已点击"允许"授权

### Q4：头像显示为默认图标
**A：** 
- 开发工具中会显示默认图标，这是正常的
- 需要在真机上测试才能看到真实头像

## 调试技巧

### 查看云函数日志
1. 打开云开发控制台
2. 进入"云函数"
3. 点击login函数
4. 查看"日志"选项卡
5. 查看是否有错误信息

### 查看数据库数据
1. 打开云开发控制台
2. 进入"数据库"
3. 选择users集合
4. 查看是否有用户数据记录
5. 检查数据格式是否正确：
   ```json
   {
     "_openid": "xxx",
     "avatarUrl": "https://...",
     "nickName": "用户昵称",
     "createTime": {...},
     "updateTime": {...}
   }
   ```

### 控制台调试
在浏览器控制台或微信开发者工具控制台中：
```javascript
// 查看全局数据
const app = getApp()
console.log('openid:', app.globalData.openid)
console.log('userInfo:', app.globalData.userInfo)

// 手动调用云函数测试
wx.cloud.callFunction({
  name: 'login',
  success: res => console.log('login结果：', res),
  fail: err => console.error('login失败：', err)
})
```

## 注意事项

1. **wx.getUserProfile必须由用户主动触发**
   - 不能在页面加载时自动调用
   - 必须绑定到按钮的点击事件

2. **真机测试很重要**
   - 开发工具和真机表现可能不同
   - 头像在开发工具中通常是默认图标

3. **用户可以拒绝授权**
   - 应该有友好的提示
   - 允许用户重新尝试授权

4. **数据安全**
   - 不要在客户端存储敏感信息
   - 使用云函数处理用户数据
