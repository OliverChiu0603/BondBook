# 登录引导功能说明

## 功能概述
在用户首次进入小程序时，会显示一个友好的登录引导弹窗，引导用户授权登录以使用完整功能。

## 功能特点

### 1. 智能显示时机
- **首次进入**：用户首次打开小程序时自动显示
- **未登录状态**：只要用户未登录就会在首页显示
- **防止骚扰**：每天只显示一次，如果用户选择"暂不登录"，当天不再弹出

### 2. 登录引导内容
弹窗包含以下信息：
- 欢迎标题和描述
- 登录后的功能权益：
  - ✓ 与家人共享账本
  - ✓ 数据云端同步
  - ✓ 多设备访问
- "立即登录"按钮
- "暂不登录"选项

### 3. 用户体验优化
- **延迟显示**：页面加载500ms后才显示弹窗，避免突兀
- **优雅动画**：弹窗带有淡入和滑入动画效果
- **可关闭**：点击遮罩层或"暂不登录"都可以关闭
- **记忆功能**：记住用户选择，避免重复打扰

## 使用流程

### 用户路径1：立即登录
1. 打开小程序
2. 看到登录引导弹窗
3. 点击"立即登录"
4. 在授权窗口中点击"允许"
5. 登录成功，弹窗自动关闭
6. 可以使用完整功能

### 用户路径2：暂不登录
1. 打开小程序
2. 看到登录引导弹窗
3. 点击"暂不登录"
4. 弹窗关闭，可以继续使用基础功能
5. 当天不再显示登录引导
6. 第二天重新打开时会再次显示引导

### 用户路径3：稍后登录
1. 选择"暂不登录"跳过引导
2. 进入"设置"页面
3. 点击"点击登录"按钮
4. 完成授权登录

## 实现细节

### 核心逻辑
```javascript
async _checkUserLogin() {
  await app.waitForReady()
  const userInfo = await app.getUserInfo()
  const hasUserInfo = !!userInfo
  
  if (!hasUserInfo) {
    const lastSkipDate = wx.getStorageSync('login_guide_skip_date')
    const today = new Date().toDateString()
    
    // 今天还没显示过则显示
    if (lastSkipDate !== today) {
      setTimeout(() => {
        this.setData({ showLoginGuide: true })
      }, 500)
    }
  }
}
```

### 存储键值
- **login_guide_skip_date**: 存储用户最后一次跳过登录的日期
- 格式：JavaScript Date.toDateString() 返回的字符串
- 例如："Fri May 09 2026"

### 样式设计
- 遮罩层：60%黑色透明度
- 弹窗：白色背景，圆角24rpx
- 动画：淡入效果 + 向上滑入效果
- 主题色：与小程序主题色保持一致

## 配置选项

### 调整显示间隔
如果要修改显示频率，可以调整存储逻辑：

**每次都显示**：
```javascript
// 移除日期检查逻辑
if (!hasUserInfo) {
  setTimeout(() => {
    this.setData({ showLoginGuide: true })
  }, 500)
}
```

**永久跳过**：
```javascript
// 使用永久标记
const hasSkipped = wx.getStorageSync('login_guide_skipped')
if (!hasUserInfo && !hasSkipped) {
  // 显示引导
}

// 跳过时设置标记
wx.setStorageSync('login_guide_skipped', true)
```

**每3天显示一次**：
```javascript
const lastSkipTime = wx.getStorageSync('login_guide_skip_time')
const now = Date.now()
const threeDays = 3 * 24 * 60 * 60 * 1000

if (!hasUserInfo && (!lastSkipTime || now - lastSkipTime > threeDays)) {
  // 显示引导
}

// 跳过时记录时间戳
wx.setStorageSync('login_guide_skip_time', Date.now())
```

## 常见问题

### Q1：为什么每天都要弹出？
**A**：为了平衡功能推广和用户体验，我们选择每天提醒一次。如果觉得频繁，可以修改为每周一次或其他频率。

### Q2：能否让用户永久关闭？
**A**：可以。在"暂不登录"旁边添加"不再提示"选项，点击后设置永久标记。

### Q3：已登录用户会看到弹窗吗？
**A**：不会。弹窗只在 `hasUserInfo` 为 false 时才显示。

### Q4：如何调整延迟时间？
**A**：修改 `setTimeout` 中的延迟值，默认是500ms。

### Q5：在哪里可以手动触发登录？
**A**：用户可以随时进入"设置"页面，点击顶部的"点击登录"按钮。

## 设计理念

这个登录引导设计遵循以下原则：
- **非强制**：用户可以选择暂不登录
- **有理由**：清楚告知登录的好处
- **不骚扰**：每天最多一次，不会频繁打扰
- **易操作**：一键登录，流程简单
- **可绕过**：多种方式可以关闭弹窗

通过这种方式，我们在推广登录功能和保持良好用户体验之间取得了平衡。
