# 权限控制系统更新说明

## 问题描述
原系统存在安全漏洞：任何人获得分享码后可以直接访问账本，可能通过穷举法访问他人数据。

## 解决方案
实现完整的用户认证和权限审批系统：

### 1. 用户身份认证
- 用户登录获取微信头像、昵称和OpenID
- 用户信息保存到云数据库users集合
- 在设置页面显示登录状态和用户信息

### 2. 访问权限控制
- 使用分享码访问账本需提交申请
- 创建者需批准后才能访问
- 创建者本人无需审批

### 3. 审批管理
- 创建者可查看待审批请求列表
- 显示待审批数量徽章提醒
- 支持批准或拒绝操作

## 主要文件变更

### 云函数
- `cloudfunctions/login/index.js` - 更新：支持保存用户信息
- `cloudfunctions/getSharedPersons/index.js` - 更新：添加权限验证
- `cloudfunctions/requestJoinBook/` - 新增：申请加入账本
- `cloudfunctions/manageJoinRequest/` - 新增：管理加入请求
- `cloudfunctions/getPendingRequests/` - 新增：获取待审批列表

### 小程序页面
- `app.js` - 添加用户信息管理方法
- `pages/settings/settings.js` - 添加登录和审批管理功能
- `pages/settings/settings.wxml` - 更新UI显示用户信息和待审批入口
- `pages/settings/settings.wxss` - 添加样式支持

### 数据库结构
**新增集合：users**
- _openid: String
- avatarUrl: String
- nickName: String
- createTime: Date
- updateTime: Date

**books集合新增字段：**
- pendingUsers: Array[{openid, nickName, avatarUrl, requestTime}]
- approvedUsers: Array[String]

## 使用流程

### 用户登录
1. 打开设置页面
2. 点击"点击登录"
3. 授权获取信息

### 申请访问账本
1. 获取分享码
2. 输入分享码点击"加入账本"
3. 如需审批则点击"提交申请"
4. 等待创建者审批

### 创建者审批
1. 设置页面显示待审批数量
2. 点击"待审批加入请求"
3. 选择用户并批准或拒绝

## 安全性提升
✅ 防止穷举法访问
✅ 所有访问需明确授权
✅ 用户身份可追踪
✅ 创建者完全控制访问权限
