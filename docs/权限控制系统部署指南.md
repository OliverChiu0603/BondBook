# 账本分享权限控制系统 - 部署指南

## 更新内容

本次更新实现了完整的用户认证和权限控制系统，解决了账本分享码可被穷举访问的安全漏洞。

## 主要功能

### 1. 用户身份认证
- 用户登录获取微信头像和昵称
- 在设置页面显示用户信息
- 用户信息保存到云数据库

### 2. 账本访问权限控制
- 使用分享码访问账本需要创建者批准
- 申请加入账本流程
- 创建者可以审批或拒绝加入请求

### 3. 待审批请求管理
- 创建者可以查看所有待审批请求
- 显示待审批请求数量徽章
- 一键批准或拒绝

## 部署步骤

### 1. 创建云数据库集合

需要创建一个新的集合：**users**

在微信开发者工具的云开发控制台中：
1. 进入"数据库"
2. 点击"新建集合"
3. 输入集合名称：`users`
4. 权限设置：
   - 所有用户可读（用于显示用户信息）
   - 仅创建者可写

### 2. 更新 books 集合权限

为了支持新的字段，确保 books 集合包含以下字段：
- `pendingUsers`: Array - 待审批的用户列表
  - `openid`: String - 用户openid
  - `nickName`: String - 用户昵称
  - `avatarUrl`: String - 用户头像
  - `requestTime`: Date - 申请时间
- `approvedUsers`: Array - 已批准的用户openid列表

### 3. 部署新的云函数

需要部署以下新增和更新的云函数：

#### 更新的云函数：
1. **login** - 已更新，支持保存用户信息
2. **getSharedPersons** - 已更新，添加权限验证

#### 新增的云函数：
3. **requestJoinBook** - 申请加入账本
4. **manageJoinRequest** - 管理加入请求（批准/拒绝）
5. **getPendingRequests** - 获取待审批的请求列表

### 4. 云函数部署命令

在微信开发者工具中，右键点击以下云函数文件夹，选择"上传并部署：云端安装依赖"：

```
cloudfunctions/login/
cloudfunctions/getSharedPersons/
cloudfunctions/requestJoinBook/
cloudfunctions/manageJoinRequest/
cloudfunctions/getPendingRequests/
```

## 使用说明

### 用户首次使用
1. 打开小程序，进入"设置"页面
2. 点击"点击登录"按钮
3. 授权获取微信头像和昵称
4. 登录成功后，用户信息将显示在设置页面顶部

### 创建者分享账本
1. 进入"设置"页面
2. 点击"分享 / 加入账本"
3. 复制或分享6位分享码给他人
4. 其他用户使用分享码申请加入后，会收到待审批提示
5. 点击"待审批加入请求"查看并审批

### 用户加入他人账本
1. 进入"设置"页面
2. 点击"分享 / 加入账本"
3. 输入6位分享码
4. 点击"加入账本"
5. 如需审批，会提示"提交申请"
6. 等待创建者审批后即可访问

### 创建者审批请求
1. 在"设置"页面会看到"待审批加入请求"（有数量徽章）
2. 点击查看待审批列表
3. 选择一个请求
4. 选择"批准"或"拒绝"

- [ ] 创建者可以看到待审批请求数量

## 安全说明

### 已解决的安全问题
✅ 防止通过穷举分享码访问他人账本
✅ 所有访问需要创建者明确批准
✅ 用户身份可追踪（显示头像和昵称）

### 注意事项
- 创建者本人访问自己的账本无需审批
- 已批准的用户可以持续访问，除非创建者移除
- 拒绝的用户可以重新申请

## 向后兼容性

本次更新完全向后兼容：
- 现有账本数据不受影响
- 老用户首次使用新功能时需要登录
- books 集合会自动添加新字段（pendingUsers, approvedUsers）

## 问题排查

### 问题：登录后看不到头像
- 检查 users 集合是否创建成功
- 检查 login 云函数是否正确部署
- 查看云函数日志是否有错误

### 问题：无法提交加入申请
- 确认用户已登录
- 检查 requestJoinBook 云函数是否部署
- 确认分享码正确

### 问题：创建者看不到待审批请求
- 检查 getPendingRequests 云函数是否部署
- 确认当前查看的是自己的账本（不是共享账本）
- 查看云函数日志
