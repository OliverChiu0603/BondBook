# BondBook

一款基于微信小程序云开发的人情往来记账工具，用于记录收支、人情对象与往来明细。

## 功能

- 新增、批量新增和查看人情往来记录
- 按人员管理记录，并统计收入、支出与汇总数据
- 支持事件详情查看
- 支持共享账本、加入申请与协作者管理
- 使用云函数处理账本、人员、记录和共享关系

## 技术栈

- 微信小程序原生框架（WXML / WXSS / JavaScript）
- 微信云开发（CloudBase）数据库与云函数

## 本地运行

1. 安装并打开微信开发者工具。
2. 导入本项目目录。
3. 在微信开发者工具中配置自己的小程序 AppID 和云开发环境。
4. 在云开发控制台创建/部署 `cloudfunctions` 目录中的云函数及其依赖。
5. 编译并运行小程序。

## 目录说明

```text
cloudfunctions/  云函数：账本、共享、登录及协作者管理
components/      可复用小程序组件
pages/           页面及页面逻辑
utils/           通用工具函数
docs/            数据库与使用说明
```

## 注意事项

项目配置中的 AppID 仅是应用标识，不是密钥。公开部署前，请使用自己的云开发环境，并不要将 AppSecret、访问令牌或生产数据库凭据提交到仓库。
