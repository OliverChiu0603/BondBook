# BondBook

一款基于微信小程序云开发的人情往来记账工具，用于记录收支、人情对象与往来明细。-- 微信搜索小程序  **礼簿BondBook**

## 功能介绍

### 人情往来记录

- **按人员建档**：为亲友、同事等往来对象建立档案，集中查看每个人的全部来往记录。
- **收支双向记录**：每条记录可标记为“送出”或“收入”，并记录金额、日期、事项和备注。
- **单条与批量录入**：既可快速补充一笔往来，也可在同一表单中连续录入多条记录，适合节日或婚宴后集中整理。
- **编辑与删除**：可在人员详情中修改或删除已保存的记录。
- **人员关系绑定**：支持将有关联的人员档案绑定在一起，方便从同一关系网络中跳转查阅。

### 查询与统计

- **首页总览**：展示送出总额、收入总额和已建档人数。
- **快速筛选与搜索**：可按“全部 / 有送出 / 有收入”筛选人员，并通过关键词定位对象。
- **按事项聚合**：统计页会按事项汇总记录；点击某个事项可进入详情，查看对应的全部往来明细。
- **明细追溯**：从人员或事项两个入口都能回到具体记录，便于核对账目。

### 多账本与共享协作

- **多账本管理**：可创建、切换和管理多个独立账本，例如家庭账本、婚礼账本或个人往来账本。
- **分享码邀请**：账本创建者可生成分享码，受邀人可通过分享入口申请加入。
- **审批机制**：创建者可查看待处理的加入申请，并选择批准或拒绝。
- **协作者管理**：可查看账本协作者，并移除不再需要访问权限的成员。
- **共享视图切换**：加入他人账本后可在自己的账本与共享账本之间切换，或退出共享视图。

### 账户与个性化

- **微信云开发登录**：登录后将数据关联至用户账号，并支持编辑昵称、头像等资料。
- **主题切换**：内置橙色、蓝色、绿色和深色主题。
- **数据清理**：账本创建者可执行清空账本操作；该操作会删除账本内的人员和记录，应谨慎使用。
- **反馈入口**：设置页提供意见反馈入口，便于收集使用问题和改进建议。

### 数据与安全边界

- 数据通过微信云开发的数据库和云函数存储、处理，客户端不直接操作核心数据。
- 云函数负责账本、人员、记录、共享申请及协作者权限等业务逻辑。
- 单个用户账本的记录数量设置了上限，以避免异常数据占用过多资源。

## 技术栈

- 微信小程序原生框架（WXML / WXSS / JavaScript）
- 微信云开发（CloudBase）数据库与云函数

## 本地运行

1. 安装并打开微信开发者工具。
2. 导入本项目目录。
3. 在微信开发者工具中配置自己的小程序 AppID 和云开发环境。
4. 在云开发控制台创建/部署 `cloudfunctions` 目录中的云函数及其依赖。
5. 编译并运行小程序。

## 目录说明

```text
cloudfunctions/  云函数：账本、共享、登录及协作者管理
components/      可复用小程序组件
pages/           页面及页面逻辑
utils/           通用工具函数
docs/            数据库与使用说明
```

## 注意事项

项目配置中的 AppID 仅是应用标识，不是密钥。公开部署前，请使用自己的云开发环境，并不要将 AppSecret、访问令牌或生产数据库凭据提交到仓库。
